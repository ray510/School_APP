# JEV 學校比較

## 功能

正式站 `/compare?ids=<2–4個資料組ID>&year=2027` 同時展示 JEV 證據對照及官方欄位對照。三學段均適用。不是排名、錄取機率、學校品質評分或泛用聊天機械人。

此版使用已發布的 `jev-1.13.0` 真實模型結果，而非每按一次比較重新向模型發問。共同點、記載差異及不確定狀態由可測試的程式整理；**不得把它描述成新一次多校聯合模型推論**。前端不需 API key，私人筆記不會送往模型。後續需要新的多校文本判斷，應另行設計伺服器權限、限流及證據驗收。

## 比較規則

- 只比較2–4個不同的同學段資料組，維持使用者所選次序，不按品質排序。
- 使用同一 data_id，並選定同一來源及概覽版本；不將2025、2026或不同校址合併為同一事實。
- 模型結果的 source_id、row、record_sha256 必須全部對應所選學校內的年度來源。
- 正面／明確否定需有原文證據；引文按Unicode code point offsets核對，與Python來源切片一致。
- 只要是 REVIEW、INVALID_RESPONSE、API_ERROR、NOT_ANALYZED，便保留狀態，不讀 proposed_verdict 當答案。
- 共同提及只表示送審片段均有提及，不保證安排、時數、質素或現況相同。
- 提及對未提及，只叫「記載差異」；不能說前者獨有或後者沒有。
- 提及對明確否定，顯示「來源記載相反」，仍保留年份與當屆限制。
- 沒有直接對應的年度來源，提供同名概覽搜尋入口，由使用者核對地址後重新選校；不自動借用另一資料組。
- 模型版本缺失或不同時，不合成確定共同結論。

## 介面

比較頁預設展示六個主題，也可只看共同提及、記載差異或未能比較項目。每校可展開原文、欄位、行號、來源版次及模型；官方分類／收費仍有獨立對照表。JSON匯出含資料版本、分析方法、選校ID及證據，不含私人筆記。

`RootApp.vue` 將比較頁獨立成 `ComparePage.vue`，其他頁仍使用原有 FullApp。比較入口及網址不變；返回選校後可重新選取學校。
